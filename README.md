# Customer Trends Data Analysis

## Description
This project analyzes customer trends using SQL, Python, and Power BI. 
It includes data cleaning, exploratory data analysis, and interactive dashboards.

## Technologies Used
- SQL (MySQL/PostgreSQL)
- Python (Pandas, Matplotlib, Seaborn)
- Power BI
- Jupyter Notebook

## Features
- Data cleaning and preprocessing
- Customer segmentation analysis
- Sales trend visualization
- Interactive Power BI dashboard
